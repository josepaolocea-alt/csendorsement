Trello Not connected
Downloads your open All Tasks as a Trello-ready CSV file to import manually — no connection needed.

Or live-sync: pushes your records to a Trello board as cards, laid out in four columns — ALL TASK, DID Order/Cancel, Done / Resolved, Pending RR / RO — one card per entry. Re-syncing updates the same card (and moves it to the right column if its status changed) instead of creating duplicates. Records moved to Trash are archived in Trello on the next sync; restoring a record reopens its card. Your key & token are saved only on this device, never in the shared app — the token is like a password to your Trello, so keep it private.
